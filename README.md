## RackNerd 的补货机制：先分清两套体系

RackNerd 的便宜套餐分两种，搞混了就会白等。

一种是**限时活动款**。新年促销、黑色星期五这类活动发出来的套餐属于这一类，比如 2026 新年促销里的 1 GB 年付 $11.29 款，开卖后很快售罄，商品页现在还挂着 Sold Out 的状态，官方的态度很明确：优惠套餐卖完后不补货，等下一轮活动再上新。

另一种是 **specials 特价款**。这是官方长期挂在特价页面上的年付 KVM VPS，按年结算、续费同价、下单即时开通，属于常态化在售——你今天去页面，这 5 款基本都能直接买。所谓「补货」，更多发生在这套体系里的具体机房：某个机房卖空了会从下拉列表里消失，等官方加了新节点再恢复可选。
